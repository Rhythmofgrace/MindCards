# Mindcards

A minimal infinite-canvas flashcard mind map for multi-subject learning. Drag to pan, scroll to zoom, and click questions to reveal their answers.

## Features
- **Multiple Subjects Support**: Switch seamlessly between subjects like Design Thinking, Computer Networks, or any custom subjects.
- **Bilingual (English & Hinglish)**: Switch languages on the fly—even live on the canvas while reading flashcards!
- **Hierarchical Navigation**: Subjects -> Units -> Topics -> Mind Map Flashcards with smooth back navigation at every level.
- **Customization Toolbar**: Customize question & answer font size, font family (Excalifont / Inter), card width, text colors, and focus opacity.
- **Dark Mode & Center Canvas**: Fully responsive with dark/light themes.

## Quick Start
Open `index.html` in any browser, or run a local server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
