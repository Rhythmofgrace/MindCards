[Topic: Q5 - Q8: Algorithms, Learning Types & Applications]

Q: 5. Define an algorithm.
A:
An algorithm is a finite, step-by-step sequence of well-defined computational instructions.
- Function: Takes inputs, processes them through logical steps, and produces a valid output.
- In ML: Optimizes mathematical parameters to recognize patterns from training data.

Q: 6. What is supervised learning?
A:
Supervised Learning is a category of ML where algorithms learn from labelled training data.
- Input & Target: Both input features (X) and correct output labels (Y) are provided during training.
- Objective: Learns a mapping function Y = f(X) to accurately predict labels for new, unseen data.

Q: 7. What is unsupervised learning?
A:
Unsupervised Learning is a category of ML where algorithms analyze unlabelled data.
- No Supervision: Data has input features (X) without any target labels (Y).
- Objective: Discovers inherent groupings, hidden patterns, and data distributions (e.g. clustering).

Q: 8. Give two examples of Machine Learning applications.
A:
Machine Learning powers diverse everyday real-world systems:
- Email Spam Filtering: Automatically identifies and diverts spam messages.

[Topic: Q9 - Q12: Features, Labels, Matrices & Tensors]

Q: 9. What is a feature in Machine Learning?
A:
A feature is an individual measurable property or variable used as an input to a model.
- Representation: Forms columns in structured datasets, denoted as input vector x.
- Example: Age, height, weight, and blood pressure are features for predicting health status.

Q: 10. What is a label in Machine Learning?
A:
A label is the final ground-truth target variable that a supervised model learns to predict.
- Role: Provides the correct output answer during training to compute prediction error.
- Example: 'Spam' or 'Not Spam' in email classification; 'Pass' or 'Fail' in student results.

Q: 11. Define a matrix.
A:
A matrix is a two-dimensional rectangular array of numbers arranged into rows and columns.
- Notation: An m × n matrix has m rows and n columns.
- Example: A = [[1, 2], [3, 4]] represents a 2 × 2 square matrix storing numerical features.

Q: 12. What is a tensor?
A:
A tensor is a generalized multidimensional mathematical data container.
- Dimension Hierarchy: 0D tensor is a scalar, 1D is a vector, 2D is a matrix, 3D+ is a higher-order tensor.
- Deep Learning: Color images are represented as 3D tensors (Height × Width × RGB Channels).


[Topic: Q13 - Q16: Vectors, Eigenvalues, Eigenvectors & Scalars]

Q: 13. What is a vector?
A:
A vector is an ordered 1-dimensional array of numbers representing magnitude and direction.
- Types: Row vector [x₁, x₂] or column vector [x₁, x₂]ᵀ.
- ML Role: Represents a single data sample's feature values in an n-dimensional feature space.

Q: 14. Define eigenvalue.
A:
An eigenvalue is a scalar scalar factor (λ) by which an eigenvector scales during transformation.
- Scaling Effect: Indicates how much the eigenvector stretches, shrinks, or reverses.
- Formula: Av = λv (where A is square matrix, v is eigenvector, λ is eigenvalue).

Q: 15. Define eigenvector.
A:
An eigenvector is a non-zero vector (v) whose spatial direction remains unchanged under transformation.
- Invariant Direction: Matrix multiplication only scales its length, never rotating its line of action.
- Characteristic Equation: Av = λv (only valid for square matrices).

Q: 16. What is a scalar?
A:
A scalar is a single numeric quantity having only magnitude with no directional component.
- Dimension: A 0-dimensional tensor.
- Examples: 5, -12, 3.14; hyper-parameters like learning rate (α) and regularization factor (λ).


[Topic: Q17 - Q20: Linear Algebra & Matrix Types]

Q: 17. What is Linear Algebra?
A:
Linear Algebra is the mathematical branch dealing with linear equations, vectors, and matrices.
- ML Foundation: Serves as the primary computational language for handling multi-variable data.
- Core Tools: Vector spaces, matrix transformations, dot products, eigenvalues, and decompositions.

Q: 18. What is a square matrix?
A:
A square matrix is a matrix having an identical number of rows and columns (m = n).
- Order: An n × n matrix is called a square matrix of order n.
- Properties: Required for calculating determinants, matrix inverses, and eigenvalues/eigenvectors.

Q: 19. What is the transpose of a matrix?
A:
The transpose of matrix A (denoted Aᵀ) is obtained by flipping rows and columns.
- Transformation: The element at row i, column j moves to row j, column i (Aᵀ_ji = A_ij).
- Dimension Swap: If A is m × n, then Aᵀ is n × m.

- Unsupervised Learning: Models trained to detect patterns and groupings on unlabelled data.

A:
Matrix addition satisfies foundational algebraic properties under dimension conformity:

Q: 12. What are eigenvalues and eigenvectors?

- Eigenvalue (λ): The scalar scaling factor that stretches, compresses, or reverses eigenvector v.
- ML Application: Principal Component Analysis (PCA) uses eigenvectors to identify axes of maximum data variance.


[Topic: Q13 - Q15: Matrix Multiplication, Role & Transpose]

Q: 13. What is matrix multiplication?
A:
Matrix multiplication computes the dot product of rows from matrix A with columns of matrix B:
- Dimensional Requirement: Columns in A must equal rows in B (if A is m × k and B is k × n, product AB is m × n).
- Non-Commutative: In general, matrix multiplication is not commutative: AB ≠ BA.
- Concrete Example: [1, 2] × [3, 4]ᵀ = (1 × 3) + (2 × 4) = 3 + 8 = 11.
- In Neural Networks: Forward pass computation calculates layer activations as Z = WX + b.

Q: 14. Explain the role of Linear Algebra in Machine Learning.
A:
Linear Algebra is the core mathematical engine driving machine learning algorithms:
- Compact Data Representation: Tabular datasets are modeled as design matrices (X) and target vectors (y).
- High-Speed Vectorized Computing: GPU hardware accelerates parallel matrix multiplications in deep networks.
- Dimensionality Reduction: PCA extracts dominant feature directions via eigendecomposition and SVD.
- Parameter Optimization: Ordinary Least Squares (OLS) calculates optimal weights using (XᵀX)⁻¹Xᵀy.

Q: 15. What is the transpose of a matrix? Give an example.
A:
The transpose of matrix A (denoted Aᵀ) exchanges row indices with column indices:
- Rule: Element at row i and column j moves to row j and column i: (Aᵀ)_ji = A_ij.
- Dimension Change: An m × n matrix becomes an n × m transposed matrix.
- Example: If A = [[1, 2], [3, 4]], then Aᵀ = [[1, 3], [2, 4]].
- ML Usage: Transpose aligns vector dimensions to compute inner products and dot products (xᵀw).

Q: 8. Describe the important properties of matrices.
A:
Matrix algebra exhibits distinct properties that govern data transformations and algorithms:
- Commutative Addition: A + B = B + A (valid when dimensions match).
- Associative Addition & Multiplication: (A + B) + C = A + (B + C) and (AB)C = A(BC).
- Distributive Law: A(B + C) = AB + AC.
- Identity Element: Multiplying by identity matrix leaves matrix unchanged: AI = IA = A.
- Transpose Properties: (A + B)ᵀ = Aᵀ + Bᵀ, (Aᵀ)ᵀ = A, and (AB)ᵀ = BᵀAᵀ (reverses order).
- Non-Commutative Multiplication: In general, AB ≠ BA (order of transformation matters fundamentally).


[Topic: Q9 - Q10: Eigenvalues, Eigenvectors & Matrix Operations]

Q: 9. Explain eigenvalues and eigenvectors with a suitable example.
A:
Eigenvalues and eigenvectors identify invariant directions and scale factors during linear transformations:
- Characteristic Equation: Av = λv or (A − λI)v = 0. Non-trivial solutions exist if determinant |A − λI| = 0.
- Concrete Example: Let diagonal matrix A = [[2, 0], [0, 3]].
- Finding Eigenvalues: |[[2 − λ, 0], [0, 3 − λ]]| = (2 − λ)(3 − λ) = 0 ⇒ λ₁ = 2, λ₂ = 3.
- Finding Eigenvectors: For λ₁ = 2: (A − 2I)v = [[0, 0], [0, 1]][x, y]ᵀ = [0, 0]ᵀ ⇒ y = 0, choosing x = 1 yields v₁ = [1, 0]ᵀ.
- For λ₂ = 3: (A − 3I)v = [[−1, 0], [0, 0]][x, y]ᵀ = [0, 0]ᵀ ⇒ x = 0, choosing y = 1 yields v₂ = [0, 1]ᵀ.
- ML Application: Principal Component Analysis (PCA) uses eigenvectors of the covariance matrix as principal axes of variance.

Q: 10. Discuss the importance of matrix operations in Machine Learning.
A:
Matrix operations form the core computational framework of machine learning algorithms:
- Tabular Data Organization: Datasets with N samples and D features are stored compactly as N × D matrices.
- Linear Regression Closed-Form: Normal Equation solves optimal weights analytically: w = (XᵀX)⁻¹Xᵀy.
- Neural Network Forward Pass: Layer outputs are computed in one vectorized operation: a = σ(W · x + b).
- Covariance & Correlation: Covariance matrix C = (1/N) XᵀX captures pairwise feature relationships.
- Hardware Optimization: Matrix operations map natively onto SIMD vector units, GPUs, and TPUs for extreme parallelism.

[Topic: Q5 - Q8: Tensors, Matrix Properties, Eigenvalues & Matrix Computations]

Q: 5. What are tensors? Explain different tensor operations with suitable examples.
A:
A tensor is a geometric object that maps geometric vectors, scalars, and other tensors to numerical arrays across arbitrary dimensions:
- Structural Hierarchy: Rank-0 (Scalar), Rank-1 (Vector), Rank-2 (Matrix), Rank-3 (Volume/Color Image), Rank-4 (Batch of Video Frames).
- Element-Wise Arithmetic: Addition, subtraction, and Hadamard multiplication (A ⊙ B) performed on identical tensor shapes.
- Tensor Contraction & Matrix Multiplication: Summing over specified index pairs; for matrices C_ij = Σ_k A_ik B_kj.
- Transposition & Permutation: Rearranging tensor coordinate axes (e.g. PyTorch channel-first NCHW to TensorFlow channel-last NHWC).
- Broadcasting & Reshaping: Automatically expanding lower-rank tensors across compatible dimensions during operations without memory replication.
- Deep Learning Role: Forms the fundamental computational primitive in PyTorch, TensorFlow, and TPU hardware.

Q: 6. Explain the different properties of matrices and discuss their importance in Machine Learning.
A:
Matrix algebra provides the formal algebraic rules enabling scalable data representation and manipulation:
- Algebraic Properties: Addition is commutative (A + B = B + A) and associative ((A + B) + C = A + (B + C)); Multiplication is associative ((AB)C = A(BC)) and distributive (A(B + C) = AB + AC).
- Non-Commutative Multiplication: In general, AB ≠ BA; transformations applied in different sequences yield different spatial mappings.
- Transpose Identities: (A + B)ᵀ = Aᵀ + Bᵀ, (AB)ᵀ = BᵀAᵀ, and (Aᵀ)ᵀ = A.
- Invertibility: A square matrix has an inverse A⁻¹ such that AA⁻¹ = I if and only if determinant det(A) ≠ 0.
- Importance in ML: Enables closed-form linear regression solutions, vectorized neural network propagation, covariance matrix analysis, and spectral clustering.

Q: 7. Define eigenvalues and eigenvectors. Explain how to calculate eigenvalues and eigenvectors of a matrix with an example.
A:
Eigenvalues and eigenvectors describe axes of invariant direction and their corresponding scaling factors under linear transformation:
- Definition: For an n × n matrix A, a non-zero vector v is an eigenvector if Av = λv for scalar eigenvalue λ.
- Step 1 (Characteristic Equation): Solve |A − λI| = 0 to obtain the characteristic polynomial and roots (eigenvalues).
- Step 2 (Eigenvectors): For each λ, substitute into (A − λI)v = 0 and solve the homogeneous system for non-trivial vector v.
- Worked Example: Let A = [[2, 0], [0, 3]]. Characteristic equation: |[[2 − λ, 0], [0, 3 − λ]]| = (2 − λ)(3 − λ) = 0 ⇒ λ₁ = 2, λ₂ = 3.
- For λ₁ = 2: [[0, 0], [0, 1]][x, y]ᵀ = [0, 0]ᵀ ⇒ y = 0, choosing x = 1 gives v₁ = [1, 0]ᵀ.
- For λ₂ = 3: [[−1, 0], [0, 0]][x, y]ᵀ = [0, 0]ᵀ ⇒ x = 0, choosing y = 1 gives v₂ = [0, 1]ᵀ.
- ML Significance: Core mechanism of Principal Component Analysis (PCA) to project data along directions of maximal variance.

Q: 8. Explain different matrix operations used in Machine Learning, such as matrix addition, subtraction, multiplication, transpose and inverse.
A:
Matrix operations provide the core computational building blocks of machine learning algorithms:
- Addition & Subtraction: C = A ± B where C_ij = A_ij ± B_ij; used for updating neural layer bias vectors and computing residual errors.
- Matrix Multiplication: Product C = AB where C_ij = Σ_k A_ik B_kj; powers dense layer forward passes, embedding projections, and convolutional filters.
- Matrix Transpose: Aᵀ flips axes (row i ↔ col j); aligns vector shapes for inner products and calculates gram matrices (XᵀX).
- Matrix Inverse: A⁻¹ satisfies AA⁻¹ = I; for 2 × 2 matrix [[a, b], [c, d]], A⁻¹ = (1/(ad − bc)) [[d, −b], [−c, a]] when det(A) ≠ 0.
- Analytical Solutions: Closed-form parameter estimation in Ordinary Least Squares: w = (XᵀX)⁻¹Xᵀy.
- Hardware Acceleration: Highly optimized BLAS/cuBLAS libraries execute these operations across massively parallel GPU CUDA cores.

Q: 3. What mathematical derivations and calculation steps must be practiced?
A:
Examiners evaluate systematic step-by-step mathematical working:
- Characteristic Equation: Setting up |A − λI| = 0 and writing the characteristic polynomial.
- Eigenvalue Solutions: Finding roots λ₁ and λ₂.
- Eigenvector Substitution: Setting up (A − λI)v = 0 for each eigenvalue and solving the linear equations.
- Matrix Inversion: Computing determinant (ad − bc) and applying the adjoint matrix formula.

Q: 4. What conceptual distinctions are essential to master across Unit 1?
A:
Ensure conceptual clarity on foundational dichotomies:
- Supervised vs Unsupervised: Labelled data mapping y = f(x) vs unlabelled structure discovery.
- AI vs ML: Broad field of intelligent agents vs specific data-driven pattern learning.
- Matrix vs Tensor: 2D tabular array vs generalized N-dimensional container (e.g. RGB image as 3D tensor).
- Feature vs Label: Independent input variable (X) vs dependent prediction target (Y).
